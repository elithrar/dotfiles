# Install skills

Install all skills from this repository:

```sh
npx skills add elithrar/dotfiles --skill '*'
```

Install a specific skill by name:

```sh
npx skills add elithrar/dotfiles --skill wow-addon-development
```

Follow the prompts to choose your agent. Add `--global` to make the skills available across projects, or `--agent codex` to target Codex directly. Repeat `--skill` to select multiple skills.

See the [skills CLI documentation](https://github.com/vercel-labs/skills) for other agents and options.
