# Anti-slop editing

Make small phrasing changes that remove filler without flattening voice. Preserve facts, citations, technical claims, paragraph structure, and the author's argument unless the user asks for a broader rewrite. Stylistic patterns cannot establish whether a person or model wrote a passage.

Read the whole piece to understand its voice. Flag phrasing only when it adds no meaning or repeats a formula; preserve deliberate fragments, parallelism, humor, and useful contrast. When a candidate could be an intentional choice, leave it or explain the tradeoff.

For a detailed pass or a contested edit, read [references/tells.md](references/tells.md) for patterns and examples. Do not treat its vocabulary as banned words.

For a review request, return the material findings and suggested edits. For an edit request, apply the changes and reread the affected passages for meaning and rhythm. Follow the requested output format; explain only significant edits, and omit a change log when the user asks for just the revised text.
